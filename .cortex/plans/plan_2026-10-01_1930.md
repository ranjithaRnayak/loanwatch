## Implementation steps

1. **`app/environment.yml`** — declare `snowflake-snowpark-python` and `streamlit` (1.35.0).

2. **`app/streamlit_app.py`** — set page config, define 4 pages with `st.navigation()` + `st.Page()`, render footer on every page via a helper.

3. **`app/pages/1_Chat.py`** — Chat page:
   - Use `st.chat_input` + `st.session_state` message history.
   - On submit, call `SNOWFLAKE.CORTEX.DATA_AGENT_RUN` with the full message history, passing `thread_id` from previous response metadata for multi-turn.
   - Parse the JSON response `content` array: render `type=text` as markdown, `type=table` as `st.dataframe`, extract SQL from `tool_result` for display in an expander.
   - Show citations (DOC_ID, PARA_REF) from search tool results.

4. **`app/pages/2_Signals.py`** — Signals page:
   - Load `LOANWATCH.OUT.SIGNALS` joined to nothing extra (BORROWER_NAME already in table).
   - Three `st.selectbox` filters: Borrower (multi), EWS Category, Severity.
   - Display filtered table via `st.dataframe`.
   - Row selection via `st.selectbox` on SIGNAL_ID; on selection show `st.expander` with the EVIDENCE array (formatted JSON) and CLAUSE_REF.

5. **`app/pages/3_Actions.py`** — Actions page:
   - Borrower selector from `LOANWATCH.RAW.BORROWERS`.
   - Four buttons: Create Finding, Prepare RFA Note, Provisioning Return, Draft STR.
   - Each button calls the corresponding SP via `session.sql("CALL ...")`.collect().
   - Parse the VARIANT return, display the generated text (NARRATIVE / NOTE_TEXT / REPORT_TEXT / DRAFT_TEXT) as markdown.
   - RFA Note button auto-passes the finding_id from the Create Finding result.

6. **`app/pages/4_Audit.py`** — Audit page:
   - Simple `SELECT * FROM LOANWATCH.OUT.AUDIT_LOG ORDER BY EVENT_TS DESC LIMIT 50`.
   - Display as `st.dataframe`.

7. **`sql/40_streamlit.sql`** — deployment SQL:
   - PUT all files to `@LOANWATCH.APP.LOANWATCH_STAGE` (create stage if needed).
   - `CREATE OR REPLACE STREAMLIT LOANWATCH.APP.LOANWATCH_UI` with `FROM '@LOANWATCH.APP.LOANWATCH_STAGE/app'`, `MAIN_FILE='streamlit_app.py'`, `QUERY_WAREHOUSE='LW_APP_XS'`.

8. **Deploy** — execute the PUT + CREATE STREAMLIT via SQL.

9. **Append to PROMPTS.md** — prompt + outcome + app URL.
